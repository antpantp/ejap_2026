# Author decisions before publishing

The code-only package is prepared for review and manual upload. It has not been uploaded or connected to any account.

- The package includes the MIT licence selected by the author. The copyright notice uses the collective name "PRBS VO2peak prediction contributors"; replace it with the preferred rights-holder names if appropriate.
- Add the final article title, author list, publication identifier if available, and repository URL. Citation metadata has not been invented.
- Confirm the data-access statement with the data custodians. No claim is made that data can be supplied on request or redistributed publicly.
- Check the journal's actual repository, licence, archiving, and data-access requirements. Its policy text was not supplied, so repository preparation does not by itself establish compliance.

No participant recordings, outcome tables, fitted models, manuscript drafts, notebook outputs, credentials, or prior Git history are included. Source code retains analysis configuration such as pseudonymous participant IDs used for checks and figure examples.
